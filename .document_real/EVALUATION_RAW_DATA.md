- Mean = 173 / 40 = 4.325 ≈ **4.33**

### Standard Deviation Calculation Example

**U1. The system interface is easy to use:**
- Variance = Σ(xi - μ)² / n
- Variance = [(0×1²) + (1×2²) + (3×3²) + (18×4²) + (18×5²)] / 40 - 4.33²
- Variance = [0 + 4 + 27 + 288 + 450] / 40 - 18.75 = 19.225 - 18.75 = 0.475
- Standard Deviation = √0.475 ≈ **0.75**
